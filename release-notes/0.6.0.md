# Release notes for sbmlsim-web 0.6.0

The drawing of a model is read at the size its package drew it: a click enlarges it to the window, and the column it sits in grows with the page instead of staying at 560 px.

## Features

- **A click enlarges the drawing.** A model drawing is dense and wide, and in the column of a page its labels are small: the anatomical figure of a whole-body model is about 1900 px wide, which is a third of that in the column, where a reader can neither read an organ nor aim at one. `<sbmlsim-figure>` now shows the drawing in a modal dialog at the size of the window. The button in the corner of the figure opens it, and so does a click on any place of the drawing which opens no panel, which is everything that is not a control. A click on a control of the enlarged drawing reports its path and closes the dialog, so a reader aims at an organ in the large drawing and lands back on the panels it opened; a click beside the drawing, the close button and Escape close it without reporting anything.

  The drawing is not copied into the dialog, it moves there and back, so the ids inside the svg stay unique, the controls and the marks are the ones the page decorated and one listener serves both places. The figure keeps the height the drawing had while it is away, so the page behind the dialog does not jump. The new parts are `zoom`, `overlay`, `stage` and `close`.

- **The figure column grows with the page.** A page with a figure gave it a column of 560 px and every pixel beyond that to the panels, so a wider window made the drawing no bigger. The column is now half of the shell, from 560 px up to 1100 px, and the grid beside it keeps the room of a card of 480 px at every width the column is given; below 1088 px of shell the figure is above the grid, centred, as before.
