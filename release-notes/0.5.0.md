# Release notes for sbmlsim-web 0.5.0

A page draws the figure of its model and a reader selects the panels beside it by clicking the drawing, the controls a page shares sit in one card above the grid, and an app carries an information view of its own.

## Features

- **The element `<sbmlsim-figure>`** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). It draws the figure an app declares and dispatches `sbmlsim-figure-select` with the key path of the part a reader clicked, the `data-k` keys of the drawing joined with `/`. Its `figure`, `marked` and `labels` are properties and are replaced and never mutated, since the element watches them shallowly. A part of the drawing which opens no panel of the page is decoration: no pointer, no role, out of the tab order, so a drawing never offers a control which does nothing.
- **A page selects its panels from the drawing** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). A page with `figure` draws the figure beside its grid; a click adds the panels that part opens and a second click removes them. The shell keeps the choice in the attribute `selection`, the ids of the panels shown and comma separated, and dispatches `sbmlsim-selection` with them, also when a change of the page or of the variant puts the selection back to what the page declares as `shown`. A page which sets `selection` itself restores a state it chose, which gives a deployment an address for a selection. The panes of a selection ask the endpoint for the scan the declared panels ask for, so selecting readouts costs no further simulation.
- **One settings card above the grid** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). What the panels of a page share is controlled once: the logarithmic switch of every plot, which shows whether the panels are all logarithmic, none or mixed, the draws, the Reset of the page (the shared knobs, the scale, the draws and the own controls of the panels, the selection kept) and the line of the last run. The knobs card lost the Reset of its own, so a screen carries one Reset instead of three, and a panel keeps its own switch and its own Reset.
- **An app has an information view** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). The last tab, `Information`, is a value of `page` (`page="information"`, with `sbmlsim-page` as any tab emits): it shows the title, the citation, the licenses and the versions which simulated the app, and stops the panels until a page tab brings them back. It is there for an app of one page as well, which is what a model package writes.
- **`register` names the figure element** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). `register(tagName, appTagName, figureTagName)`, and the shell reaches its panels under the tag it placed them with, so the Reset of a page and the information view work under a renamed tag as they do under the default one.

## Changes

- **The glimepiride example states the spread it computed** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). The parameter table carries the coefficient of variation beside the deviation in every cell, and the page has one draws control rather than two: the field of the settings card is the only one and the table follows the draws the panels ran with. The note under the table names the run its numbers came from and keeps saying it is computing until every analyte has its draws, so it never announces a draw count over columns which are still empty, and a panel a reader removes loses its column.
- **The contract fixture is the payloads of the service as it answers them** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). It carries the figure of an app and the `figure` and `shown` of a page, so the end to end tests run against an sbmlsim which declares a figure.

## Fixed

- **The mark of a selected part was the hover of the pointer** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). Both were the same halo, so a reader could not tell what was shown from what was under the pointer. A marked part carries the halo of the accent and a hovered one a neutral one, and the mark is drawn around the group and never as a stroke on its children, which painted over the boxes, the arrowheads and the labels of a drawing.
- **The documentation claimed what the app no longer does** ([#10](https://github.com/matthiaskoenig/sbmlsim-web/pull/10)). The README named a Reset of the shared controls which is gone and a navigation which is absent for an app of one page although the tab row is now always drawn, and it named neither `selection` nor `draws`. The published types carry `setLog` of a panel, which the documentation promised, and the class comments carry `selection` and `sbmlsim-selection`.
