# Release notes for sbmlsim-web 0.2.0

The panels run without a server. An endpoint `local:<name>` is answered by a function of the page itself, so the elements draw the panels of a model whose simulations run in the browser of the reader: the panel endpoint of [sbmlsim-core](https://matthiaskoenig.github.io/sbmlsim-core/) answers the routes of the service of sbmlsim from the bundle `python -m sbmlsim.serve --export` writes (sbmlsim >= 0.25.0), on a pool of Web Workers. The package has a documentation site, https://matthiaskoenig.github.io/sbmlsim-web/, whose first example is the [glimepiride app](https://matthiaskoenig.github.io/sbmlsim-web/examples/glimepiride/), a static page of four panels and twelve example patients simulated on sbmlsim-core.

## Features

- **An endpoint inside the page** ([#1](https://github.com/matthiaskoenig/sbmlsim-web/pull/1)). `registerEndpoint(endpoint, fetcher)` (`sbmlsimWeb.registerEndpoint` of the IIFE build) registers a function with the signature of `fetch` (`EndpointFetch`) under an endpoint which starts with `local:` (`LOCAL_PREFIX`). The client hands it every request it would hand `fetch` and reads its `Response` exactly as one of the network: the status, a 503 with a `Retry-After`, the JSON, the contract check, the shape guards, the timeout and the abort. An element may connect before its endpoint is registered; its requests wait for the registration within their timeout and signal, so a page registers from a module script.
- **A documentation site with Zensical** ([#1](https://github.com/matthiaskoenig/sbmlsim-web/pull/1)): overview, getting started, every attribute, method and event of both elements, embedding, endpoints, the contracts and the examples, built with the bundle of the checkout (`npm run docs`) and published to GitHub Pages from `main`.
- **The glimepiride app** ([#1](https://github.com/matthiaskoenig/sbmlsim-web/pull/1)), an example of the documentation and a page of its own, built by `scripts/glimepiride.sh` from sbmlsim, sbmlsim-core and pkdb_models.

## Changes

- A request whose signal is aborted before it is sent fails `aborted` at once.
- The end to end tests run against sbmlsim 0.25.0, whose panels are integrated to their output times; the contract fixture is its answer.
