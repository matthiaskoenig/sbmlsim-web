# Release notes for sbmlsim-web 0.1.1

The release which is published by the trusted publishing of npm: the workflow `publish` proves itself to npm with the OIDC token of GitHub instead of a token of npm, so the package carries the provenance of the commit and the workflow which built it, and no token of npm is stored. 0.1.0 was published by hand and carries none.

## Fixes

- **The package is published with provenance and without a stored token.** `publish.yml` drops the secret `NPM_TOKEN` and checks that npm is 11.5.1 or newer, the first which publishes with trusted publishing, before it builds.
- **The README embeds 0.1.1**, the version its CDN lines pin.
