# Release notes for sbmlsim-web 0.3.0

A page of an app can show many readouts side by side: a page of small panels lays out four cards across the width of a page, each drawing its figure small, which the default apps of the models of pkpdsim use for the readouts of a model under the knobs a page shares. The end to end tests run against sbmlsim 0.27.1.

## Features

- **A page of small panels** ([#3](https://github.com/matthiaskoenig/sbmlsim-web/pull/3)). A page with `size: "small"` (`AppPage.size` of sbmlsim 0.28) lays out cards of at least 280 px, four in the width of a page, and gives every panel `size="small"`; a page without the field, of a service before sbmlsim 0.28, is regular.
- **The size of a panel** ([#3](https://github.com/matthiaskoenig/sbmlsim-web/pull/3)). The attribute `size` of `<sbmlsim-panel>`: `small` draws the figure from 160 px of width, 0.7 of its width high and from 150 to 260 px, `regular` (the default) as before.

## Changes

- The end to end tests run against sbmlsim 0.27.1 (`SBMLSIM_REF`), the contract fixture written again against it (a `spec_hash`, which covers the version of sbmlsim). The snippets of the documentation load sbmlsim-web 0.3.0 and the panel endpoint of sbmlsim-core 0.6.0.
