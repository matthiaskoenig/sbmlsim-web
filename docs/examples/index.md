# Examples

Pages which run the panels and the apps of models with these elements follow here. Each example is a page of this section with its assets in a folder of its name, e.g. `examples/<model>.md` and `examples/<model>/`, and runs in the browser of the reader on an [endpoint inside the page](../endpoints.md#an-endpoint-inside-the-page), so it needs no server.

- [Glimepiride](glimepiride.md): the whole-body PBPK model of glimepiride and its metabolites as the app of four panels and twelve example patients, simulated on sbmlsim-core.
